# 手写数字识别练习

一个个人学习项目：上传手写数字图片，使用训练好的 K 近邻模型预测数字，并在网页上显示结果。

## 已实现

- 上传图片并显示预测结果。
- 基于 scikit-learn 的 `load_digits` 数据集训练和评估模型。
- 将图片转换为 8×8 灰度数据，再交给模型预测。

## 使用方法

1. 使用 Python 创建并选择项目环境，在该环境中安装 `requirements.txt` 中的依赖。
2. 在项目目录运行 `app.py`。
3. 打开运行窗口显示的本地地址，选择图片并点击“开始识别”。

建议上传白色背景、黑色笔画且数字居中的图片。目前模型对图片大小、笔画和位置比较敏感，预测结果可能出错；网页手写功能尚未实现。

## 项目文件

- `app.py`：Flask 页面和预测接口。
- `templates/`、`static/`：网页和交互脚本。
- `digits_model.joblib`：训练好的模型，运行预测时需要此文件。
- `inspect_data.py`、`grey_process.py`：数据探索、模型实验和图片预处理练习。

本项目用于学习，不保证对任意真实图片都能准确识别。
